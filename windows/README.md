# Lumen для Windows 11

Windows использует общий интерфейс и источники Lumen через Expo Web, Electron и отдельные платформенные адаптеры. Android и ATV используют прежние реализации.

## Запуск и сборка

Из корня репозитория, PowerShell:

    npm install --legacy-peer-deps
    Push-Location windows
    npm install
    node node_modules/electron/install.js
    Pop-Location
    npm run windows:start
    npm run windows:build

Portable: dist/windows-portable/Lumen-Windows-x64-Portable.exe.
При первом запуске рядом с EXE создаётся папка data. Держите EXE в доступной для записи папке; переносите его вместе с data, чтобы сохранить настройки, закладки, историю, кеш и загрузки.

## Управление

Чёрная верхняя панель: полный экран, свернуть, развернуть, закрыть. F11 переключает полноэкранный режим; Escape выходит из него. В полном экране панель появляется при наведении к верхнему краю. Пробел управляет паузой в плеере.

## Google Drive

Используется прежний формат облачных данных. «Подключить Google Drive» открывает системный браузер для выбора аккаунта и разрешения синхронизации. Ручного ввода client ID/secret нет: официальный Desktop-клиент включён в EXE и принадлежит тому же проекту Lumen Cloud Sync, что и Android. Выбирать JSON пользователю не нужно. Файл windows/google-desktop-client.json хранится локально и требуется для сборки Windows; он исключён из Git. Для собственного Google Cloud проекта нужен OAuth клиент типа Desktop app с разрешённым Drive API; client secret импортируется из JSON автоматически. Для доступа к существующим Android-бэкапам Desktop OAuth клиент должен принадлежать тому же Google Cloud приложению: appDataFolder изолирован между приложениями. Другой проект создаст отдельное облачное хранилище; перенести данные можно экспортом/импортом бэкапа. OAuth приложение Lumen Cloud Sync опубликовано в режиме In production 13 октября 2026 года. Главная страница: https://sadikh94.github.io/lumen/; политика: https://sadikh94.github.io/lumen/privacy.html. При переносе конфигурации на собственный Google Cloud проект его также нужно опубликовать: в режиме Testing вход разрешён только добавленным тестовым аккаунтам. Токены защищены Windows DPAPI. При переносе папки на другой компьютер может потребоваться повторный вход.

## Платформенные ограничения

Android TV launcher channels, автоматическое переключение частоты экрана Android, установка APK и Android-обработка системных субтитров не применяются к Windows. Просмотр не требует установленного Android/WSA.


Интерфейс Windows: Настройки → Режим интерфейса → Мобильная версия / TV версия. В TV режиме доступны управление стрелками/Enter и мышью. Отдельный переключатель «Вкладки в Досмотреть» включает Досмотреть / Обновление серий / Загрузки и в TV режиме.

Windows: ESC закрывает открытый выбор/меню, возвращает из плеера или информации о фильме; в полном экране сначала выходит из него. Свайп с зажатой левой кнопкой переключает вкладки, вертикальное перетаскивание прокручивает списки. Выделение текста доступно в информации о контенте и полях ввода. Заголовки вкладок и рейтинги постеров увеличены на 30%.

Кнопка мини-плеера сворачивает то же окно до видео, скрывает основной интерфейс и оставляет его поверх других окон. Верхняя полоска мини-плеера позволяет перетаскивать его; «Развернуть» или ESC возвращает прежний интерфейс и размеры. Положение и размер мини-плеера сохраняются в portable data/mini-window.json.

## MyDockFinder и постоянная иконка

Для доков, сопоставляющих приложения по пути EXE, используйте portable-версию в папке:

    npm run windows:export
    node windows/build-folder.cjs

Результат: dist/windows/Lumen/Lumen.exe. Перенесите всю папку Lumen в постоянное место. Удалите старую закреплённую иконку portable-лаунчера в MyDockFinder и закрепите именно Lumen.exe из новой папки. Все файлы этой папки необходимы для работы. Данные сохраняются в её подпапке data; для переноса существующего профиля копируйте прежнюю data только при закрытом приложении. Сборщик не перезаписывает существующую папку Lumen.
Обновление 2026-10-18: после запуска упакованного приложения рядом с EXE создаётся Lumen.lnk с тем же AppUserModelID, что и у окна. Для MyDockFinder предпочтительна папочная сборка: `node windows/build-folder.cjs Lumen-Dock`. Сначала перенесите всю папку в постоянное место, один раз запустите её Lumen.exe, затем замените старую закреплённую иконку на созданный Lumen.lnk. При переносе папки повторный запуск EXE обновляет собственный ярлык; чужие ярлыки с другим идентификатором не перезаписываются. Поведение группировки в стороннем доке зависит от его способа сопоставления окон.

Windows использует отдельную компактную панель добавления в закладки в стиле ATV: прокручиваемый список папок, галочки справа и кнопка создания категории под списком. Эта панель применяется в обоих режимах Windows и не меняет Android-интерфейс.
